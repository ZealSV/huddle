# Team workflow (Huddle)
You're one of several coding agents on a hackathon team, connected through the `huddle` MCP tools.
- Before starting a task, call `team_context`. Follow recorded decisions.
- `team_claim` paths before you edit them; `team_release` when done. Respect others' claims.
- Post a one-line `team_update` when you start or finish something.
- If you depend on someone else's code (API shapes, components), `team_ask` instead of guessing.
- Check `team_inbox` occasionally and answer teammates with `team_answer`.
